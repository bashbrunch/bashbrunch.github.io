Features

Written in Bash

BashBrunch is written entirely in Bash, making it lightweight, fast-running, low-overhead, extensible, and compatible with almost any Unix-like system.

Minimal Tools

BashBrunch gives AI only a minimal set of tools, which are simple and focused but these tools are powerful enough to accomplish a wide range of tasks.

Control-Passing Oriented

BashBrunch is designed to be control-passing oriented, meaning that the AI assistant keeps the control with it for as long as it wants, unless the user force quits. This allows AI assistants to operate more autonomously.

Lower System Footprint

BashBrunch has a minimal system prompt, allowing AI assistants to digest more context about the tasks, tools, and environment instead of trying to understand the harness.

Fully Customizable

Since BashBrunch is written in Bash, it is easy to extend and customize with additional scripts and functions. Add Providers, Plugins, and other extensions to tailor the experience to your specific needs.

Compatible with Small AI

BashBrunch is designed to be compatible with small AI models with limited resources and capabilities. Including lightweight and efficient models that don't support tool calls but can still perform basic tasks.
