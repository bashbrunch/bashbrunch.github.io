## BashBrunch Landing Page

The official landing page for [BashBrunch](https://bashbrunch.attaditya.space/), a minimal terminal-based AI coding harness built entirely in Bash.

## Structure

- `index.html` - Landing page markup and styles
- `web/` - Images and other static assets used by the page

## Development

The landing page is built with plain HTML and CSS, with no framework or build step required.

Open `index.html` in a browser or serve the directory using any static file server.

## Deployment

Deploy the HTML file and `web/` directory to any static hosting provider. Ensure the asset paths remain valid.
